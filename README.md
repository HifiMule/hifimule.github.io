## What is HifiMule
HifiMule is a desktop application that bridges your Open Source Media Server and legacy mass-storage MP3 players. Browse your library, pick what you want, and sync it to your device with delta transfers and resume support.

## Compatibility
We currently support [Jellyfin](https://jellyfin.org/) and [Navidrome](https://www.navidrome.org) or other Subsonic API compatible server

We currently support USB storage compatible player (Rockbox, etc...), and MTP compatible player (Smartwatches).
